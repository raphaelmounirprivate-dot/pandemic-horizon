# Pandemic Horizon — candidat 0.19

Extraire entièrement l'archive Windows x64, puis lancer PandemicHorizon.exe. Godot n'est pas requis. Le jeu fonctionne hors ligne ; les sauvegardes et préférences restent dans le profil utilisateur Godot sur ce PC. Les anciens exports et sauvegardes ne sont pas effacés.

Depuis la 0.13 : exploration du monde, transports observés, évolutions intégrées avec achat explicite, actualités et courbes, agent NACRE, profil enrichi facultatif de 18/21 évolutions et huit événements supplémentaires. La 0.19 ajoute mouvements réduits, lecture agrandie et sons originaux facultatifs avec volume. Les courbes utilisent trait et tirets en plus des couleurs.

Les profils classiques conservent leurs règles historiques. Une partie enrichie utilise le format 5, reconnu à partir de 0.18 compatible. Le tutoriel reste classique. Les paramètres de confort ne modifient pas la simulation. Les marqueurs et chiffres sont fictifs ; la carte géographique ne transforme pas les régions en pays simulés.

Consulter GUIDE-JOUEUR.md pour jouer, VERSION.json pour identifier le commit et l'empreinte de l'exécutable, licences/ pour Godot et Natural Earth. L'emblème, les icônes et sons synthétiques sont créés dans le code du projet ; aucun son échantillonné externe ajouté.

3 141 contrôles automatiques passent avant livraison candidate, avec captures aux dimensions 1280×720, 1920×1080 et 2395×1060. Les essais physiques, auditifs, sur un second PC et de compréhension sont encore à faire dans TESTS-JOUEURS.md. Cette version candidate n'est pas une 1.0 validée par des joueurs. Aucun binaire GitHub n'est publié automatiquement : l'archive est produite localement, le code est poussé séparément.
